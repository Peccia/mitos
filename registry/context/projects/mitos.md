# Mitos

Mitos closes the agentic SDLC loop. It is the registry and compiler that materializes one
canonical body of context across every tool and machine, so any harness, including a planning
harness, can ground a request in it before a coding harness executes it.

## Navigation

Each repo below carries its own agent-facing context file, which loads automatically when
you work inside that checkout. This node is orientation and the project's document map
only — it deliberately does not repeat what those files already say.
